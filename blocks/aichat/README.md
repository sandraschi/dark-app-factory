# AI Chat Block

AI chat UI with Ollama/LM Studio integration — streaming chat, personality selector, and conversation history.

**Triggers**: chat, ai, assistant, llm, ollama, bot, conversation, support

**Env vars**:
| Variable | Default | Description |
|----------|---------|-------------|
| `CHAT_MODEL` | `llama3.1:8b` | Default LLM model name |
| `CHAT_BASE_URL` | `http://localhost:11434/v1` | OpenAI-compatible API base URL |

**API endpoints**: `/api/chat/send`

**Dependencies**: (none)
