# Webshop Block

E-commerce webshop — product catalog, cart, inventory management, order processing with Stripe checkout integration.

**Triggers**: shop, store, ecommerce, product, webshop, cart, checkout, inventory, catalog

**Env vars**: (none)

**API endpoints**: `/api/products`, `/api/products/{id}`, `/api/cart`, `/api/orders`

**Dependencies**: Requires `stripe` block.
