# Social Block

Social media integration — feed embeds, share buttons, social login, and follow links for major platforms.

**Triggers**: social, instagram, twitter, facebook, linkedin, share, follow, social.media

**Env vars**:
| Variable | Default | Description |
|----------|---------|-------------|
| `SOCIAL_INSTAGRAM` | — | Instagram profile URL |
| `SOCIAL_TWITTER` | — | Twitter/X profile URL |
| `SOCIAL_FACEBOOK` | — | Facebook page URL |
| `SOCIAL_LINKEDIN` | — | LinkedIn profile URL |
| `SOCIAL_YOUTUBE` | — | YouTube channel URL |

**API endpoints**: `/api/social/links`

**Dependencies**: (none)
