# i18n Block

Internationalization — translation management, locale detection, language switcher, pluralization, and RTL support.

**Triggers**: translate, language, i18n, locale, multilingual, german, french, spanish, deutsch, english

**Env vars**:
| Variable | Default | Description |
|----------|---------|-------------|
| `DEFAULT_LOCALE` | `en` | Default locale code |
| `SUPPORTED_LOCALES` | `en,de,fr,es,it` | Comma-separated supported locales |

**API endpoints**: `/api/i18n/translations`, `/api/i18n/locales`, `/api/i18n/translate`

**Dependencies**: (none)
