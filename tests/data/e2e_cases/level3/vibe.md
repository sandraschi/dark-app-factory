# Void Inventory: DTU Dashboard

> A high-fidelity dashboard for tracking celestial items with integrated pricing from a Simulated Digital Twin Universe (DTU) service.

## Integration Details
- Connect to DTU (Digital Twin Universe) at `http://localhost:10737`.
- Register with DTU to receive a unique Galaxy ID.
- Use DTU to fetch "Void pricing" for all inventory items.

## Features
- Multi-page navigation (Items, Pricing, Galaxy Config).
- Items: A list of space-debris items with current stock.
- Pricing: Real-time price simulation provided by DTU.
- Galaxy Config: Form to update DTU Galaxy identity.
- Visual: Cinematic space-themed background.
