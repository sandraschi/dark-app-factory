# Shadow Tasks: Private Productivity

> A minimalist, local-first task manager with a focus on dark mode and keyboard efficiency.

## Core Logic
- Use FastAPI as the backend (mock storage in memory).
- Use Vanilla JS for the frontend.
- Tasks should have a title, status (active/shadow), and priority.

## Features
- Add new tasks via a simple input.
- Mark tasks as "Shadow" (completed).
- Priority badges (Void, High, Normal).
- Filter by status.
