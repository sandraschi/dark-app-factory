# Dark Coffee: The Midnight Roast

> A premium landing page for a fictional high-end coffee brand that only roasts at night.

## Visual Direction
- Ultra-dark theme.
- Deep gold accents.
- Cinematic typography.

## Features
- Hero section with "Embrace the Dark" CTA.
- Our Process: Detailed night-roasting explanation.
- The Menu: List of 3 signature roasts (Obsidian, Eclipse, Void).
- Rituals: A section about coffee brewing.
